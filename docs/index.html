Who pays for the correction?

AI phone agents ask callers to repeat themselves when they are not sure what they heard. I measured who gets asked. The same safety rule makes callers with some French accents repeat themselves more often than others.

By Haris Folas. Born in Cameroon, now in Canada, where I build AI phone agents for small businesses.

The person this is for

Picture a plumber in Québec who lets an AI agent answer the phone at night. Before going live she picks one setting: how sure the agent must be before it accepts what a caller said. Below that line it says “Sorry, could you repeat that?”

This project is the check she can run before switching it on. Does that one setting treat a caller from Yaoundé the same way as a caller from Paris?

The line is set once, for everyone, on a first group of callers, so that about 5 % of calls go through with a mistake. It is the same rule for every caller. Does it cost every caller the same?

Where it fails

Real examples from the test speakers: what the person read, next to what Whisper wrote.

ReadZengi retourne alors assiéger Homs.WhisperRéalisé par neo035

A hallucination: Whisper invented a video-credit line, a phrase common in its training subtitles. It happened once in 1,440 transcriptions. On a phone line, an invented sentence is worse than a wrong word.

ReadIl ne s’agit que d’une ruse de Kestutis pour gagner du temps.WhisperIl ne s’agit que d’une ruse mais qu’est-ce que tu utilises pour gagner du temps.

Rare names break it for every accent. Common Voice sentences come from Wikipedia and are full of them, which is why I also checked the results without any sentence that contains a name.

ReadL’oiseau le plus lent.WhisperLoiseau de poulain.

A short sentence leaves Whisper no context to recover from one unclear sound. Callers giving a name or a street number are in exactly this situation.

How I made sure it holds

    What this does not show

    • Each Common Voice group has 50 speakers (25 in the test half), Yaoundé 30 (15). That is enough to see a gap of about 5 points, not smaller ones.
    • “Sub-Saharan Africa” is what speakers chose in Common Voice. It pools many countries and accents.
    • People read Wikipedia sentences. They were not making real calls, and the phone line is simulated.
    • I assume a repeated sentence is then heard correctly. Real callers who repeat may be misheard again.
    • I report several comparisons. A result with p around 0.03 on one of them is a strong hint, not a proof.

    What a business should do before going live

    • Measure how often each accent you serve is asked to repeat, not only the average error rate.
    • Test on phone-quality audio. For Sub-Saharan African speakers, the gap grew on the phone line.
    • Tell the recognizer the language, and confirm only the doubtful words instead of the whole sentence. Both help every caller; neither closes the gap on its own.
    • Always confirm names, whoever calls.

    Method. Common Voice French 27.0, 50 speakers per accent group and 4 clips each, plus 30 speakers from OpenSLR 57 (Yaoundé). Speakers were split in half before any result was looked at: one half sets the line, the other half is where results are reported. Whisper large-v3 (through Groq) with the language set to French, text normalised the same way on both sides, word error rate with jiwer, 95 % ranges from 1,000 resamples of speakers. The phone line is a 300–3,400 Hz filter with the 8 kHz telephone codec G.711. No audio from the datasets is shared here, following the Common Voice terms. Code and full results: GitHub.

    AI tools used. Whisper large-v3 (OpenAI model, run by Groq), faster-whisper small and large-v3-turbo (run on my laptop), and Claude Code (Anthropic), as a coding and writing assistant for the analysis code and this page. I chose the question, which comes from my own work building phone agents, and listened to 20 clips to check the data and the errors.
